# External & Workflow Skills

External skills from the `claude-workflow` collection provide specialized guidance for software development workflows, architecture decisions, and best practices.

## Available Skills

### [API Design](api-design.md)
REST and GraphQL API design patterns, including endpoint structure, error handling, versioning strategies, and OpenAPI documentation.

**Use when**: Designing APIs, creating endpoints, defining response formats, or implementing authentication patterns.

### [Architecture Patterns](architecture-patterns.md)
Software architecture patterns and design decisions, from simple layered architectures to complex distributed systems.

**Use when**: Designing systems, choosing architectural patterns, structuring projects, or making technology decisions.

### [Git Workflow](git-workflow.md)
Git workflows, branching strategies, commit conventions, and collaboration patterns for effective version control.

**Use when**: Working with Git, creating pull requests, managing branches, or establishing team conventions.

### [Performance Optimization](performance-optimization.md)
Performance analysis and optimization techniques for frontend, backend, and algorithmic improvements.

**Use when**: Diagnosing slowness, optimizing code, improving load times, or analyzing performance bottlenecks.

### [Project Analysis](project-analysis.md)
Systematic project structure analysis to understand tech stacks, patterns, and conventions in any codebase.

**Use when**: Starting work on a new codebase, onboarding to a project, or understanding existing architecture.

### [Testing Strategy](testing-strategy.md)
Comprehensive testing strategies following the testing pyramid, with framework recommendations and best practices.

**Use when**: Adding tests, improving coverage, setting up testing infrastructure, or designing test strategies.
