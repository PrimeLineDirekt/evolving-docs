## What It Does

The Etsy Poster Creator is a fully automated system that generates viral-optimized Etsy listings with Pinterest SEO, bilingual support (English + German), Midjourney v6/v7 prompts, and Google Trends integration. It handles everything from prompt generation to SEO optimization to Pinterest pin creation.

## Key Capabilities

### Core Features
- **Bilingual SEO Generation** - Automatic English + German listings
- **Pinterest Optimization** - Mobile-optimized titles (45-65 chars), ALT text generation
- **Google Trends Integration** - Real-time keyword analysis & seasonality detection
- **Image Validation** - Etsy 5+ images @ 2000px+ requirement check
- **Midjourney Version Selection** - Automatic V6 (baby/kids) or V7 (speed) selection
- **Mobile-First Optimization** - Designed for 44.5% Etsy app sales + 82% Pinterest mobile traffic

### Advanced Features
- **Natural Language Titles** - Anti-keyword-stuffing validation
- **Dynamic Stylize Adjustment** - Baby Room: 0-50, Normal: 50-400
- **ALT-Text Generator** - +123% Pinterest clicks through ALT text
- **Intelligent Tag Shortening** - German tags automatically shortened to ≤20 characters
- **8 Category Defaults** - Research-based settings with V6/V7 logic

## The Process

### 1. Input Collection

Three workflow modes available:

**Option A: Text-based (Traditional)**
```
Category + Motif + Style → Midjourney Prompts + SEO + Pinterest Pins
```

**Option B: Image-based**
```
Upload images → Style extraction OR SEO generation
```

**Option C: Combined**
```
Text workflow + Pinterest pins + Trend analysis + Image validation
```

Input collection includes:
- Category selection (8 options: Wall Art, Baby Room, Kitchen, etc.)
- Motif specification (main subject)
- Style selection (art style like Watercolor, Minimalist)
- Optional: color palette, mood, target market

### 2. Midjourney Prompt Generation

Generates optimized Midjourney prompts with:

- **Version Selection**: V6 for Baby/Kids rooms, V7 for faster generation
- **Stylize Values**: 0-50 for baby rooms, 50-400 for other categories
- **Aspect Ratios**: Category-specific (2:3 for Wall Art, 4:5 for Kitchen, etc.)
- **Detailed Descriptions**: Professional prompt structure

Example output:
```
Serene sunset beach, watercolor art style, soft pastel colors,
gentle waves, golden hour lighting --ar 2:3 --stylize 150 --v7
```

### 3. Bilingual SEO Generation

Creates optimized SEO for both English and German markets:

**Natural Language Title Formula:**
```
[Descriptive Adjective] + [Motif] + [Style/Medium] + [Format] + [Use Case]

✅ Good: "Serene Sunset Beach Watercolor Print - Coastal Wall Art for Living Room"
❌ Bad: "Sunset Beach Print Wall Art Poster Download Watercolor Coastal"
```

**Tag Strategy:**
```
13 Tags = 3 Broad + 5 Mid + 5 Long-tail

Broad: "wall art", "printable art"
Mid: "sunset beach print", "coastal wall art"
Long-tail: "serene watercolor sunset", "beach living room decor"
```

### 4. Pinterest Pin Optimization

Generates mobile-optimized Pinterest pins:

- **Titles**: 45-65 characters (mobile-optimized)
- **ALT Text**: SEO-rich descriptions (+123% clicks)
- **Pin Descriptions**: Hashtag-optimized with clear CTAs
- **Image Specs**: Vertical images preferred (82% mobile traffic)

### 5. Google Trends Integration

Real-time trend analysis including:

- Seasonality detection
- Trend direction (rising/declining)
- Peak months identification
- Keyword variants analysis
- Timing recommendations

### 6. Image Validation

Validates images against Etsy requirements:

- Minimum 5 images @ 2000px+
- Resolution check for all images
- Aspect ratio consistency
- First image mobile-optimization
