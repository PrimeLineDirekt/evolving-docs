## What is Evolving?

Evolving is a comprehensive enhancement system for Claude Code that provides:

- **Intelligent Orchestration** - Smart delegation to specialized agents
- **Persistent Memory** - Domain and Experience Memory across sessions
- **Knowledge Graph** - 360+ interconnected entities
- **Context Engineering** - Optimized token usage and routing
- **Automation** - Hooks, triggers, and proactive behaviors

## Quick Start

```bash
# Clone the repository
git clone https://github.com/neoforce/evolving.git

# Navigate to the project
cd evolving

# Start working with Claude Code
claude
```

## Key Concepts

### Domain Memory
Persistent project-scoped state that survives across sessions. Track progress, failures, and learnings.

### Knowledge Graph
A network of 360+ entities with 600+ relationships. Enables intelligent context loading and component discovery.

### Context Router
Maps keywords to relevant resources, ensuring you always have the right context loaded.

### Agent Swarm
Coordinated multi-agent execution for complex tasks. Delegate to specialists, not generalists.
