    Was ist Evolving?¶

    Evolving ist ein umfassendes Erweiterungssystem für Claude Code, das bietet:

    • Intelligente Orchestrierung - Smarte Delegation an spezialisierte Agents
    • Persistenter Speicher - Domain und Experience Memory über Sessions hinweg
    • Knowledge Graph - 360+ vernetzte Entitäten
    • Context Engineering - Optimierte Token-Nutzung und Routing
    • Automatisierung - Hooks, Trigger und proaktives Verhalten

    Schnellstart¶

    Schlüsselkonzepte¶

    Domain Memory¶

    Persistenter projektbezogener Zustand, der über Sessions hinweg erhalten bleibt. Verfolge Fortschritt, Fehler und Erkenntnisse.

    Knowledge Graph¶

    Ein Netzwerk aus 360+ Entitäten mit 600+ Beziehungen. Ermöglicht intelligentes Context-Loading und Komponenten-Discovery.

    Context Router¶

    Mappt Keywords auf relevante Ressourcen und stellt sicher, dass immer der richtige Kontext geladen ist.

    Agent Swarm¶

    Koordinierte Multi-Agent-Ausführung für komplexe Aufgaben. Delegiere an Spezialisten, nicht an Generalisten.
